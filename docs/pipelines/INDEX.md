# BioETL Pipelines

This directory contains documentation for individual BioETL pipelines.
Each pipeline has its own subdirectory with a README that describes
inputs, outputs, and domain-specific details.

## Available pipelines

- Activity from ChEMBL: see activity-chembl/README.md
- Assay from ChEMBL: see assay-chembl/README.md
- Target from ChEMBL: see target-chembl/README.md
- Document from ChEMBL and literature metadata: see
  document-chembl/README.md
- Test item from ChEMBL: see testitem-chembl/README.md

Use this index as an entry point when you need details about a specific
pipeline.
