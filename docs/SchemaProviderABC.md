# SchemaProviderABC[SchemaT]

## Описание

SchemaProviderABC отвечает за предоставление схем, используемых при валидации входных и выходных данных. Он возвращает абстрактный объект SchemaT, не навязывая конкретную библиотеку или формат описания схемы. Это может быть модель библиотеки проверки, TypedDict, dataclass или собственная структурированная спецификация. Реализация может поддерживать версии схем, разные схемы для разных профилей и окружений. SchemaProviderABC не выполняет саму валидацию и не преобразует данные; его задача — централизованно выдавать согласованные определения структуры. Это позволяет ValidatorABC и другие компоненты опираться на единый источник правды для формата данных и упрощает изменение схем без переписывания кода стадий и источников.
