# ErrorPolicyABC

## Описание

ErrorPolicyABC определяет стратегию реакции на ошибки в пайплайне. Он принимает исключение и контекст в виде Mapping[str, object] и возвращает значение ErrorAction, указывающее, следует ли повторить операцию, пропустить её или завершить выполнение с ошибкой. Контекст может содержать информацию о типе стадии, шаге пайплайна, количестве попыток и других факторах, релевантных для принятия решения. Реализация может кодировать сложные правила, зависящие от домена, критичности данных и типа источника. ErrorPolicyABC не исполняет retry и не управляет стадиями напрямую; он только выдает решение, которое затем реализуется PipelineBase и другими компонентами. Чёткое разделение политики ошибок и оркестрации упрощает изменение поведения при сбоях и позволяет повторно использовать те же правила в разных пайплайнах.
