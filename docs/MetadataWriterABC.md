# MetadataWriterABC[MetadataT]

## Описание

MetadataWriterABC описывает запись служебных метаданных, связанных с основными артефактами данных. Он принимает путь Path, указывающий на целевой артефакт или директорию, и объект MetadataT, который содержит структурированную информацию о запуске пайплайна, источниках, версиях схем, количествах записей и хэшах. Реализация может сериализовать метаданные в YAML, JSON или другой согласованный формат, но должна обеспечивать читаемость и устойчивость к изменениям версии данных. MetadataWriterABC не отвечает за запись самих данных и не должен дублировать логику WriterABC; он работает поверх уже созданного набора артефактов. Такой интерфейс позволяет стандартизовать структуру служебных файлов и упрощает интеграцию с системами каталогизации, lineage и анализа качества.
