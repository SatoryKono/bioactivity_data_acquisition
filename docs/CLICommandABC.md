# CLICommandABC

## Описание

CLICommandABC описывает контракт плагинной команды командной строки, связанной с пайплайнами. Он определяет свойство name, задающее имя команды, и метод run, принимающий список аргументов и возвращающий целочисленный код выхода. Реализация может запускать конкретные пайплайны, выводить их список, проверять конфигурацию, генерировать документацию и выполнять другие вспомогательные действия. CLICommandABC не навязывает конкретный фреймворк CLI и может быть адаптирован к любой внешней оболочке. Наличие единого интерфейса для команд упрощает регистрацию новых действий без правки базового ядра и позволяет строить консистентную консоль вокруг общего набора пайплайнов и конфигураций.
