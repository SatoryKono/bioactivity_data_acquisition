# /validate-config Workflow

Use together with [.windsurf/commands/validate-config.md](../commands/validate-config.md) to lint project configs.

## Inputs

- `--configs PATH|GLOB` (required)

## Steps

1. Collect the exact config glob (e.g., `configs/**/*.yaml`).
2. Run `/validate-config --configs <glob>`.
3. Inspect detected schema errors and unused keys; apply only safe autogenerated patches.
4. Record required migrations in `CHANGELOG.md` and `DEPRECATIONS.md`.

## Outputs

- `reports/config/validation.md`

## Exit Criteria

- All configs validate cleanly or issues are explicitly listed with fixes/MRs.
