# CHECKLIST_INVARIANTS

Обязательные инварианты для всех run-* и write-* команд:

- Флаги: `--config`, `--limit`, `--dry-run`, `--golden`, `--sample` (если применимо), `--set KEY=VALUE`.
- Проверка схем (Pandera) до записи.
- IO: фиксированный порядок колонок/строк, ISO-UTC, атомарная запись, запрет silent-drop колонок.
- Централизованный логгер вместо `print`.
- При `--golden` сверка хешей и размеров.
