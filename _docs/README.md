# Archive Documentation

This directory contains archived and draft documentation that is not part of the active documentation structure.

## Status

Files in this directory are:
- **Archived**: Historical documentation that may be referenced but is not actively maintained
- **Draft**: Work-in-progress documentation that has not been finalized
- **Deprecated**: Documentation that has been superseded by files in `docs/`

## Active Documentation

The active documentation structure is located in `docs/` and follows the naming conventions defined in `docs/clients/styleguide/00-naming-conventions.md`.

## Structure

- **styleguide/** - Style guide documents (some may be duplicates of `docs/clients/styleguide/`)
- **ABC documentation files** - Individual ABC class documentation (archived)
- **Architecture plans** - Historical architecture planning documents

## Migration Notes

If you need to reference content from this directory:
1. Check if equivalent content exists in `docs/`
2. If migrating content, follow the naming conventions: `NN-topic-name.md`
3. Update any cross-references to point to the new location
