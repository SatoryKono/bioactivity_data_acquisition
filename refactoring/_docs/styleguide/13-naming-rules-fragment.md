# A

| Rule ID | Описание                                                      |
| ------- | ------------------------------------------------------------- |
| NR-001  | Формат имён модулей `<layer>_<domain>_<action>[_<provider>]`. |
| NR-002  | snake_case для имён пакетов и модулей.                        |
| NR-003  | Тестовые файлы `test_<module>.py` с зеркальной структурой.    |
| NR-004  | CLI-модули начинаются с `cli_`.                               |
| NR-005  | Модули клиентов начинаются с `client_`.                       |
| NR-006  | Классы клиентов завершаются на `Client`.                      |
| NR-007  | Файлы схем имеют суффикс `_schema`.                           |
| NR-008  | Конфиги в snake_case с расширениями yaml/yml/json.            |
| NR-009  | Тестовые пути `tests/bioetl/.../test_<module>.py`.            |
| NR-010  | PascalCase для классов с допустимыми суффиксами Base/ABC.     |
| NR-011  | Функции — глагольные snake_case.                              |
| NR-012  | Константы в верхнем регистре.                                 |
| NR-013  | Исключения завершаются на `Error`.                            |
